# Guía breve de ClassNote 1.1.0

## 1. Prepara tu grupo

Abre **Configuración**. Crea el ciclo escolar con sus fechas y después su grupo con grado y nombre. Selecciona el ciclo con el que trabajarás. Cada ciclo admite un solo grupo activo; la barra lateral identifica el contexto actual.

## 2. Registra alumnos

En **Alumnos**, registra los datos y la matrícula en el grupo. Comprueba las fechas de ingreso y salida cuando correspondan. Puedes editar fichas y consultar el historial. La aplicación comienza vacía y no impone un límite de siete alumnos.

## 3. Pasa lista

Abre **Asistencia**, elige la fecha y captura el estado de cada alumno. Añade notas si lo necesitas y guarda. Espera la confirmación antes de cerrar. No registrar asistencia no equivale a marcar falta.

## 4. Organiza tareas

En **Tareas**, crea la actividad con sus fechas. Abre sus entregas y registra el estado de cada alumno. Guarda y comprueba la confirmación. Si hay cambios pendientes al salir, guarda o descarta el borrador cuando se avise.

## 5. Descarga un reporte

En **Reportes**:

1. Elige **Semanal**, **Mensual**, **Todo el ciclo** o **Fechas libres**.
2. Selecciona asistencia, actividades y tareas o lista de alumnos.
3. Usa todo el grupo o selecciona alumnos concretos.
4. Elige resumen, detalle y comentarios según lo que necesites.
5. Revisa la vista previa, exporta y elige dónde guardar el archivo .xlsx.

Solo se generan las hojas del contenido elegido. Editar el Excel no cambia los datos de ClassNote. Las lecturas y observaciones no se ofrecen en la interfaz actual.

## 6. Guarda un respaldo completo

Abre **Configuración → Respaldos y recuperación** y pulsa **Guardar respaldo completo**. Elige un archivo JSON en una ubicación privada fuera del perfil de ClassNote. Espera el mensaje de guardado y conserva copias anteriores, idealmente en otra unidad.

El respaldo incluye todos los ciclos, grupos, registros y preferencias, también lecturas y observaciones históricas aunque estén ocultas. El Excel no sirve para restaurar.

## 7. Recupera datos o cambia de PC

En **Configuración → Respaldos y recuperación**, elige **Elegir respaldo para restaurar**, revisa su información y confirma. Debes guardar primero una copia de los datos locales actuales. Restaurar los reemplaza por completo; no combina dos bases.

Puedes usar respaldos válidos 0.1.0 y 1.1.0 con esquema/formato v1. Cancelar conserva la base anterior. Al terminar, comprueba ciclo, alumnos y registros.

## Hábitos recomendados

- Haz un respaldo frecuente y siempre antes de actualizar o desinstalar.
- Protege tu sesión de Windows y los archivos JSON y Excel: ClassNote no los cifra.
- Cierra y vuelve a abrir después del primer registro para comprobar que se conservó.
- No publiques información de alumnos al pedir ayuda.

La app funciona sin cuenta ni conexión. Para instalarla en otra PC, consulta [instalación](INSTALLATION.md).
